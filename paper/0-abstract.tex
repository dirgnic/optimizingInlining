\begin{abstractpage}
\begin{abstract}{english}
In optimizing compilers, the problem of inlining has long been studied in order
to increase performance across platforms while keeping the size of applications
small. Choosing when to inline remains complicated because, in the context of a
program, functions are interconnected through the call graph, and one decision
can influence the structure of the program and the future possible
optimizations. These choices can affect both the size of the intermediate
representation and the final object file at the end of compilation.

In this thesis, the problem of inlining is treated through an offline learning
approach. Feature vectors about call sites and general graph information are
collected at the beginning of the compilation stage and are not updated after
every decision, as an online model would do. The dataset contains C/C++ files
from DCMTK, a varied public-source supplement selected for inlining relevance,
and deterministic synthetic modules generated combinatorially in order to add
controlled cases. The files pass through the Clang frontend with inlining turned
off in order to obtain LLVM IR modules, from which call sites are extracted and
feature vectors are constructed.

A set of deterministic heuristics, called teachers, is defined and run on the
feature vectors of each module. This is done in order to assign inline/no-inline
labels per call site. For each module, the teacher that reduces the rewritten IR
size the most is selected, and its decisions become part of the supervised
training set. Student models are then trained to imitate these selected teachers
through behavior cloning, and their predictions are applied by rewriting
call-site sections of LLVM IR. The reported run compiles 163 C/C++ sources,
evaluates 150 LLVM modules with local call sites, and extracts 10394 call-site
samples. On the held-out split, the selected-teacher reference reduces IR
instruction count by 1.10\% relative to never-inline, while the best held-out
student reaches a 0.61\% reduction. These results do not outperform LLVM's
production \texttt{-Oz} pipeline, but they show that ML policies can be used to
study inlining optimization instead of relying only on fixed classical
heuristics.
\end{abstract}
\end{abstractpage}

\begin{abstract}{romanian}
În optimizarea compilatoarelor, problema de inlining este de mult studiată
pentru a păstra o balanță între dimensiunea aplicațiilor și performanța
acestora. Problema alegerii contextului potrivit pentru inlining rămâne
complicată, deoarece funcțiile sunt interconectate prin intermediul grafului de
apeluri, iar o decizie poate influența structura programului și viitoarele
posibilități de optimizare. Toate aceste decizii pot influența dimensiunea
reprezentării intermediare, precum și a binarului final, la finalul etapei de
compilare.

În contextul acestei teze, problema de inlining este tratată printr-o metodă
de învățare offline, în care vectorii de atribute cu informații despre apelurile
de funcții și graful de apeluri sunt extrași la începutul compilării, fără a se
reactualiza la fiecare pas, precum ar funcționa învățarea online. Setul de date
conține fișiere C/C++ din DCMTK și alte surse publice variate, alese pe
criteriul relevanței pentru problema de inlining. Multiple surse sintetice au
fost adăugate pentru a extinde setul de date și au fost generate combinatorial,
pentru a se asigura diversitatea. Întregul set de date trece printr-un frontend
Clang cu optimizarea de inlining dezactivată pentru a se obține reprezentarea
intermediară LLVM corespunzătoare, de unde se extrag call site-urile și se
construiesc vectorii de atribute corespunzători.

Se definește un set de euristici numite profesori, care se rulează pe vectorii
de atribute ai fiecărui program pentru a se obține etichete de inline/no-inline
per call site. Profesorul care reușește să reducă numărul de instrucțiuni IR
cel mai mult pentru un anumit program este folosit în setul pentru training
supervizat. Setul de training este alcătuit astfel din reuniunea etichetelor
profesorilor care au dus la cea mai mare reducere de IR per modul. Scopul este
ca un student să fie capabil să copieze alegerile profesorilor săi, o tehnică
numită behavior cloning. Deciziile studenților sunt aplicate prin rescrieri ale
reprezentării intermediare la nivelul apelurilor de funcții. În experimentul
principal, 163 fișiere C/C++ au fost compilate cu succes, dintre care 150 aveau
apeluri locale de funcții și au rămas în setul de date. Numărul total de
apeluri analizate este 10394. Pe setul held-out, cel mai bun model a dus la o
reducere de IR de 0.61\% față de never-inline. Cel mai bun profesor, folosit ca
referință selected-teacher, a dus la o reducere de 1.10\%. Deși rezultatele nu
sunt mai bune decât LLVM \texttt{-Oz}, implementarea demonstrează că politicile
de ML pot fi folosite în locul euristicilor clasice în problema de inlining.
\end{abstract}
